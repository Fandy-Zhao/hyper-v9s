# Stage F1：真实任务条件残差可行性审计

## 结论

Stage F1 未启动 GPU 训练。仓库与现有 UCIT 数据中没有找到可以在不强行解释任务语义的前提下构造出的“旧专家提供原子功能 A，目标任务明确依赖 A 并增加功能 B”的真实任务对。按照预注册规则，本阶段记为 **不适用（task pair unavailable）**，触发 Stage F2 受控合成验证；这不是条件残差方法的通过或失败结果。

## 审计范围与判据

候选数据重点检查了 CLEVR 与 IconQA。接受的任务对必须同时满足：

1. A-only 与 A+B 的功能定义可由标注直接判定；
2. 训练和测试样本可独立划分；
3. 目标不能只是两个互不相关完整任务的拼接；
4. 不把 ImageNet-R 或 IconQA 整体事后解释为“原子功能”。

## 观察

- CLEVR 训练集 40,000 条、测试集 3,000 条。现有指令构造全部是算术操作后计数，缺少同分布、同语义体系下的 A-only 形状识别任务，不能形成可辩护的 A → A+B 依赖。
- IconQA 训练集 29,859 条。计数相关问题约占 42.18%；显式 `what shape` 类型仅 164 条（约 0.55%）。测试集中显式形状问题约占 0.53%。这些问题来自不同图像和不同题型，无法证明目标计数任务依赖一个可复用的形状识别专家。
- ImageNet-R 与 IconQA 是两个完整任务；继续把它们拆解为 A 与 B 会违反本轮“不要强行解释为原子功能”的限制。

## 停止与转移决定

由于真实任务对不可用，未训练 Independent/Conditional Residual/rank16 等 F1 对照，也没有选择性报告 seed。后续仅在 Stage F2 中使用固定 seed、离线生成、具有独立 train/val/test 和模板隔离的受控功能数据，验证 A（形状识别）、B（计数）、C（左右关系）。

Stage F1 状态：`SKIPPED_NO_DEFENSIBLE_REAL_TASK_PAIR`
